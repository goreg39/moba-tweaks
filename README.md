# Moba Tweaks

Пользовательский скрипт Tampermonkey для рабочего каталога Moba.

## Установка

1. Установить Tampermonkey и разрешить пользовательские скрипты в браузере.
2. Открыть постоянную ссылку установки:

   https://raw.githubusercontent.com/goreg39/moba-tweaks/main/moba-tweaks.user.js

3. Подтвердить установку в Tampermonkey.

## Автообновление

В `moba-tweaks.user.js` заданы `@updateURL` и `@downloadURL` на этот же постоянный raw-файл. Новая версия публикуется с увеличенным `@version`, после чего Tampermonkey может обновить установленный скрипт штатным механизмом проверки обновлений.

Синхронизацию Tampermonkey между компьютерами можно использовать одновременно с автообновлением.

## Важно

Скрипт предназначен для `https://sankt-peterburg.moba.ru/*`. Исходные названия товаров Moba не изменяются.
